# 🏥 ระบบบันทึกการจัดยา & ติดตาม Medication Error ประจำห้องยา
### (Pharmacy Daily Dispensing Workload & Medication Error Management System)

ระบบเว็บแอปพลิเคชันสำหรับกลุ่มงานเภสัชกรรม ออกแบบมาเพื่อบันทึกภาระงานการจัดยาประจำวัน สถิติผู้ป่วยนอก (OPD) ผู้ป่วยใน (IPD) และติดตามความคลาดเคลื่อนทางยา (Medication Error) รายบุคคล พร้อมแดชบอร์ดสรุปรายเดือน ตัวชี้วัดคุณภาพโรงพยาบาล (HA / NCC MERP) การส่งออก Excel และระบบพิมพ์รายงานทางการ

---

## ✨ ฟังก์ชันและความสามารถหลัก

### 1. 📊 ภาพรวมแดชบอร์ดสรุปรายเดือน (Executive Quality Dashboard)
- **การ์ดสรุปตัวชี้วัดสำคัญ (KPI Cards):**
  - ยอดจัดยารวมทั้งเดือน (Total Dispensed Prescriptions)
  - จำนวนคนไข้รับบริการรวม (Total Patients: OPD / IPD) และค่าเฉลี่ยต่อวัน
  - สถิติอุบัติการณ์ Mederror รวม (แยก การจัดยา และ การคีย์ยา)
  - อัตราความคลาดเคลื่อนในการจัดยาต่อ 1,000 ใบสั่งยา (**HA Indicator / ตัวชี้วัดมาตรฐานโรงพยาบาล**)
  - รางวัลเจ้าหน้าที่จัดยาสูงสุดประจำเดือน (Top Performer)
- **กราฟวิเคราะห์ข้อมูลอัจฉริยะ (Interactive Charts):**
  - กราฟแท่งและเส้นแสดงแนวโน้มภาระงานรายวัน (ผู้ป่วย OPD/IPD vs ปริมาณการจัดยา)
  - กราฟแท่งเปรียบเทียบยอดจัดยาสะสมรายบุคคล
  - แผนภูมิโดนัทสัดส่วนความคลาดเคลื่อนในการจัดยา (Dispensing Error Breakdown)
  - แผนภูมิโดนัทสัดส่วนความคลาดเคลื่อนในการคีย์ยา (Keying/Transcribing Error Breakdown)
- **ตารางวิเคราะห์ความแม่นยำรายบุคคล (Monthly Staff Matrix):**
  - เปรียบเทียบปริมาณจัดยา, สัดส่วนภาระงาน (%), สถิติ Mederror รายบุคคล, อัตราความผิดพลาด (%) และระดับการประเมินคุณภาพ
- **ประเด็นพัฒนาคุณภาพ (CQI Insights):** คำแนะนำเชิงรุกสำหรับหัวหน้าห้องยาในการป้องกันข้อผิดพลาดซ้ำ

### 2. 📋 บันทึกภาระงานจัดยาประจำวัน (Daily Dispensing Log)
- ตารางบันทึกประจำวันรูปแบบเดียวกับต้นฉบับห้องยา:
  - วันที่ (เช่น `2 พ.ย. 69`, `3 พ.ย. 69` ...)
  - จำนวนคนไข้ IPD และ OPD
  - คำนวณรวมคนไข้ (IPD + OPD) ให้อัตโนมัติ
  - ช่องบันทึกยอดจัดยาของเจ้าหน้าที่แต่ละคน (นายสิทธิศักดิ์, นายธรพล, น.ส.อรุณี, น.ส.จุฑามาศ, น.ส.ยุวดี ฯลฯ)
  - รวมยอดจัดยาทุกคนในแต่ละวันอัตโนมัติ
  - แถบสรุปรวมทั้งเดือน (Total Row) ที่ด้านล่างตาราง
- ฟังก์ชันค้นหาวันที่, เพิ่มข้อมูลวันใหม่, แก้ไขข้อมูลย้อนหลัง และลบข้อมูล

### 3. ⚠️ บันทึกและวิเคราะห์ Mederror รายบุคคล (Medication Error Tracking)
- **ตารางสรุป Matrix View (ตรงตามแบบฟอร์มเอกสารเดิมของโรงพยาบาล 100%):**
  - **ตารางที่ 1: ความคลาดเคลื่อนในการจัดยา (Dispensing Error)**
    - รายชื่อเจ้าหน้าที่จัดยา
    - หัวข้อ: จัดยาผิดชนิด, จัดยาไม่ครบ(เม็ด), จัดยาไม่ครบ(ยาในตะกร้า)
    - แถบสรุปสีเหลือง พร้อมช่องยอดรวมสีแดงตามแบบฟอร์ม
  - **ตารางที่ 2: ความคลาดเคลื่อนในการคีย์ยา (Keying/Transcribing Error)**
    - รายชื่อเจ้าหน้าที่คีย์ยา
    - หัวข้อ: คีย์ยาผิดชนิด, คีย์ยาไม่ครบจำนวน, คีย์ยาไม่ครบจำนวนรายการ, คีย์วิธีบริหารยาผิด, รวม
- **บันทึกอุบัติการณ์รายครั้ง (Incident Detailed Logging):**
  - วันที่เกิดเหตุ
  - หมวดหมู่ (การจัดยา / การคีย์ยา)
  - เจ้าหน้าที่ผู้รับผิดชอบ
  - ประเภทความคลาดเคลื่อน
  - ชื่อยาและรายละเอียดปัญหา (เช่น LASA, ฉลากยา, ขนาดยา)
  - ระดับความรุนแรงตามเกณฑ์สากล **NCC MERP / HA (ระดับ A - I)**
  - ผู้ตรวจพบ และ มาตรการแก้ไขเบื้องต้น
- ตารางค้นหาและกรองประวัติอุบัติการณ์ย้อนหลัง

### 4. 👥 จัดการเจ้าหน้าที่ & ตั้งค่าระบบ (Staff & Settings)
- เพิ่ม / แก้ไข / ลบ รายชื่อเจ้าหน้าที่ห้องยา (ชื่อเต็ม, ชื่อเรียกย่อ, ตำแหน่ง, สีประจำตัว)
- กำหนดสิทธิ์งานของแต่ละคน (จัดยา, คีย์ยา)
- เพิ่มหรือแก้ไขประเภทความคลาดเคลื่อน (Error Types) ได้ตามบริบทของโรงพยาบาล
- สำรองฐานข้อมูล (Backup JSON) / กู้คืนข้อมูล (Restore JSON) / คืนค่าข้อมูลตัวอย่างเริ่มต้น (Reset)

### 5. 📥 ส่งออก Excel & 🖨️ พิมพ์รายงานราชการ
- **ส่งออกไฟล์ Excel (.xlsx):** ส่งออกรายงานครบ 4 ชีทในไฟล์เดียว (ภาระงานจัดยา, Mederror การจัดยา, Mederror การคีย์ยา, รายการอุบัติการณ์)
- **พิมพ์รายงานประจำเดือน (Print Preview / PDF):** แบบฟอร์มรายงานที่เป็นทางการ พร้อมช่องลงลายมือชื่อผู้รายงานและหัวหน้ากลุ่มงานเภสัชกรรม

## 🚀 วิธีการเปิดใช้งานโปรแกรม

### วิธีที่ 1: เปิดใช้งานทันที (แนะนำ)
ดับเบิ้ลคลิกที่ไฟล์:
```
เปิดโปรแกรม.bat
```
ระบบจะเปิดเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge) ขึ้นมาที่ `http://localhost:3000` โดยอัตโนมัติ

### วิธีที่ 2: รันผ่านโหมด Development
เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:
```bash
npm run dev
```
